agent88 privacy policy

agent88 is a private, single-user application. It runs on its owner's own computer and is used only by its owner, with the owner's own Google accounts.

Data accessed

With the owner's consent, agent88 uses the Gmail API (scope gmail.modify) to list, read, send, archive and mark the owner's mail, and the Google Calendar API (scope calendar.readonly) to show the owner's calendar events.

How the data is used and stored

  • Mail and calendar data is fetched live from Google and shown to the owner. It is not copied to a database or to files; a short-lived in-memory cache is cleared when the application restarts.
  • OAuth tokens are stored in the owner's local keyring on the owner's computer.
  • No data is sold, shared with or transferred to any third party, and none is used for advertising or to train models.

Google API Services User Data Policy

agent88's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
